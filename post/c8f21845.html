skill推荐：Archify-图表生成

发表于2026-09-17|更新于2026-09-17
|总字数:1.9k|阅读时长:6分钟|浏览量:

Archify 是一个专为 AI 编程助手设计的开源 Agent Skill，旨在将代码仓库或系统描述，通过自然语言直接转化为美观、可靠且可交互的 HTML 架构图。它并非传统的在线画板，而是将绘图能力深度嵌入到 Cursor、Claude Code 等 AI 智能体的工作流中。

核心特性

Archify 试图解决传统绘图工具（如 draw.io 手动拖拽繁琐、Mermaid 复杂图表易混乱）的痛点。其核心优势在于：

  • 自然语言驱动：无需学习绘图语法，只需向 AI 描述你的系统架构或技术意图，即可生成图表。
  • 可验证的可靠性：工作流程为“生成 JSON IR → 规则验证 → 渲染”，确保生成的图表在逻辑和结构上是准确的，避免“看起来漂亮但实际有误”的情况。
  • 交互式成品：生成的 HTML 文件是独立的，支持搜索节点、追踪调用路径、切换深浅主题等交互操作，便于演示和沟通。
  • 对话式迭代：如果对图表不满意，可以直接用自然语言指令让 AI 修改，例如“加入 Redis”或“突出缓存失效后的回退路径”，无需从头重画。
  • 多格式导出：支持导出为 PNG、SVG、WebM 等格式，方便嵌入文档或分享。

支持的图表类型

Archify 目前支持五种技术图表，覆盖了大部分开发场景：

图表类型 适用场景
Architecture (架构图) 展示组件、服务、存储和系统边界，如微服务架构、云架构。
Workflow (工作流图) 描述有序的工作流程，如 CI/CD 流水线、审批流程。
Sequence (时序图) 展示调用、返回、缓存未命中等时序交互，如 API 调用链。
Data Flow (数据流图) 描绘数据的移动、转换和消费，如 ETL 管道、数据血缘。
Lifecycle (生命周期图) 表示状态、重试、等待和最终结果，如订单状态流转。

国内使用

Archify 在 Trae 与 Trae CN 中的支持情况

Trae CN 的 Skill 安装方式：

  • 项目级：将 Skill 放在项目目录下的 .trae/skills/ 中。
  • 全局级：放在 C:\Users\你的用户名\.trae-cn\skills 目录下，Trae CN 会自动解析。
  • 命令行安装：需在指令后加上 --agent trae-cn 后缀绑定，否则无法通过可视化界面管理。

实际差异：由于 Trae CN 使用国产模型（如 DeepSeek、豆包等），而 Archify Skill 本身只是一个结构化使用说明书（SKILL.md），Skill 机制本身不依赖特定模型，因此 Archify 在 Trae CN 中可以正常安装和调用。但模型能力的差异可能影响 AI 对架构描述的理解和生成质量，复杂场景下国际版模型（如 Claude、GPT）通常表现更优。

选择建议

  • 日常开发、预算敏感、网络环境受限 → 优先选 Trae CN，免费使用国产模型，国内直连，Archify Skill 可正常集成。
  • 需要 Claude/GPT 级别模型能力、复杂架构生成场景 → 考虑 Trae 国际版，但需准备国际网络环境和付费预算。
  • Archify 本身在两个版本中都能用，关键差异在于底层模型的架构理解能力，而非 Skill 机制的支持与否。

在 Trae CN 中使用 Archify

在 Trae CN 中使用 Archify，核心是通过 npx skills 命令将它安装为一个 Skill，之后就能在 AI 对话中直接调用了。

请确保环境满足以下条件：

  • Trae CN 版本：确认版本号 ≥ 3.3.21，低版本不支持 Skill 功能。
  • 运行环境：Archify Skill 依赖 Node.js，请确保已安装 Node.js ≥ 16.0，同时 npx 也会随之自动安装。

如何使用 Archify

Archify 的设计理念是“在对话中生成图表”，因此其使用方式主要围绕 AI 编程助手展开。同时，它也提供了命令行工具供高级用户或集成场景使用。

环境准备与安装

Archify 基于 Node.js，需要 Node.js 18 或更高版本。

基本用法（推荐）

安装完成后，你无需手动操作命令行。直接在支持 Skill 的 AI 编程助手（如 Cursor、Claude Code、Codex CLI、OpenCode、Raven）的对话中，用自然语言提出你的需求即可。

示例指令：

  • “分析这个代码仓库，并生成一张高层运行时架构图。”
  • “使用 archify 为这个仓库的运行时架构生成图表。”
  • “展示一个带有 JWT 认证、Redis 缓存未命中和数据库回退的 API 请求时序图。”

AI Agent 会理解你的意图，生成结构化的 JSON 数据，然后由 Archify 负责验证和渲染，最终输出一个可交互的 HTML 文件。

命令行用法（高级/集成）

对于需要将 Archify 集成到 CI/CD 管道或进行精确控制的用户，可以使用其 CLI 工具 archify/bin/archify.mjs。完整的命令包括 validate (验证)、render (渲染)、deliver (交付)、compare (对比) 等。

一个典型的手动工作流如下：

  1. 选择图表类型：根据你要回答的问题，选择对应的图表类型（如 architecture）。
  2. 编写源文件：创建一个符合 Schema 的 JSON 源文件，建议从官方示例（如 examples/web-app.architecture.json）开始修改。
  3. 验证：使用 validate 命令在渲染前检查 JSON 文件的正确性。
  1. 交付：使用 deliver 命令生成最终的 HTML 成品，该命令会冻结版本并生成可信任的交付物。

Archify 将架构图的创建从一项繁琐的“画图”任务，转变为一次自然的“对话”和“验证”过程，尤其适合需要频繁更新架构文档的开发团队。

5. 总结

  • Archify 国内主要用途：作为 AI 编程工具（Trae、Cursor 等）的 Skill，生成架构图；生成的图表也可嵌入飞书、钉钉文档。
  • Trae vs Trae CN：国际版与国内版，账号数据独立，模型和网络访问不同；Archify 在两个版本中均可通过 Skill 机制集成，但底层模型能力会影响生成质量。
