一、 VLANIF 是什么？

VLANIF 接口是一种三层的逻辑接口（在思科等设备中常被称为 SVI 接口）。物理上它并不存在，而是通过软件基于 VLAN 创建的。

核心作用：

  1. 实现 VLAN 间通信：VLAN 本质上是隔离二层广播域的，不同 VLAN 默认不能直接互通。VLANIF 接口在隔离的基础上，为这些孤立的广播域开了一个三层的“窗口”，使得数据包能够有控制地在不同 VLAN 间路由转发。
  2. 充当主机网关：每个 VLAN 对应一个 VLANIF 接口，为其配置 IP 地址后，该接口即可作为本 VLAN 内所有终端主机的默认网关，对需要跨网段的报文进行基于 IP 地址的三层转发。

关键特性：

  • 状态依赖：VLANIF 接口只有在对应的 VLAN 已经创建，且该 VLAN 内存在状态为 Up 的物理接口（或 Eth-Trunk 接口）时，VLANIF 接口状态才会变为 Up，从而进行三层转发。
  • 高效性：与传统单臂路由相比，VLANIF 在三层交换机内部实现路由，无需额外路由器或线缆，配置更简单，转发性能更高，是现代网络中实现 VLAN 间路由的首选方案。

二、 如何配置 VLANIF？

配置 VLANIF 接口遵循“先二层，后三层”的逻辑，标准流程主要分为以下几步：

  1. 创建 VLAN：在系统视图下创建所需的 VLAN。
  2. 配置物理接口加入 VLAN：将交换机连接终端的物理接口配置为 Access 模式（或 Trunk），并划入对应的 VLAN。
  3. 创建并配置 VLANIF 接口：为每个 VLAN 创建对应的 VLANIF 接口，并配置 IP 地址作为该网段的网关。
  4. 配置终端网络：为 PC 等终端配置 IP 地址，并将默认网关设置为对应 VLANIF 接口的 IP 地址。

三、 实际应用案例

案例一：企业同设备不同部门互通

这是最常用的基础场景。假设企业网络中，研发部和市场部位于同一台三层交换机上，且属于不同网段：

  • 研发部：VLAN 10，网段 192.168.10.0/24
  • 市场部：VLAN 20，网段 192.168.20.0/24

只需按上述配置在交换机上创建 VLANIF 10（IP: 192.168.10.1）和 VLANIF 20（IP: 192.168.20.1）。当研发部 PC 访问市场部服务器时，数据包先发送到本部门网关（VLANIF 10），交换机查询内部路由表后，通过 VLANIF 20 接口将数据包转发给服务器。整个过程由交换机的三层转发引擎高效完成。

案例二：作为网络出口网关与路由联动

在中小型网络中，三层交换机常作为用户的网关设备并连接出口路由器。此时，除了配置业务 VLANIF 接口外，还需要在交换机上配置静态路由或动态路由协议。

排查小贴士：如果配置后发现不同 VLAN 无法 ping 通，请按顺序检查：1. PC 的默认网关是否指向了正确的 VLANIF 地址；2. 对应的 VLANIF 接口状态是否为 UP（可通过 display ip interface brief 查看）；3. 物理接口是否正确划入了相应的 VLAN。
